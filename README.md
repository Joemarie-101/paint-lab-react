# Joe's PaintLab

A web-based application for paint color selection, mixing formulas, and project calculations for Philippine paint brands.

## Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Firebase account

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd paint-lab-react
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
```bash
cp .env.example .env
# Edit .env with your Firebase configuration
```

4. Start the development server:
```bash
npm start
```

### Available Scripts

- `npm start` - Runs the app in development mode
- `npm test` - Launches the test runner
- `npm run build` - Builds the app for production
- `npm run eject` - Ejects from Create React App (one-way operation)

## Technology Stack

- **Frontend**: React.js, HTML5, CSS3
- **Backend**: Node.js, Express.js
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **Deployment**: Cloud hosting platform

## Features

- 🎨 Comprehensive color database for Philippine paint brands
- 🧪 Precise mixing formulas with step-by-step instructions
- 📊 Material quantity calculator
- 💰 Cost estimation tools
- 📱 Mobile-responsive design
- 👤 User profile and project history
- 🔐 Secure authentication system
